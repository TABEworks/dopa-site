Dopa / 始め方

iPadでClaude Code・Codexを使う、Dopaの始め方。

Dopaは、iPadからGitHub Codespacesに接続して開発するアプリです。AIとコードが動くのはクラウド側。手元のiPadで依頼、承認、確認を進めます。

TABEworks · 2026年10月16日更新。アプリは公開準備中です。ここでは現行実装に沿って準備と操作の流れを紹介します。

必要なもの料金最初の作品既存リポジトリ作業の終え方

始める前に用意するもの

iPadとインターネット
iPadOS 17以降。AIの実行と作業場への接続にネットが必要です。
GitHubアカウント
Codespacesを利用でき、作業するリポジトリにアクセスできるアカウント。初めてなら、ガイド付き設定の途中でGitHubのアカウント作成へ進めます。
Claude CodeかCodexの認証
利用するCLIが対応するアカウント、またはAPI認証情報を用意します。AIを選ぶ操作と、認証完了は別です。Dopa内の案内に従って公式認証画面へ進みます。

GitHubのリポジトリはコードの保存先、Codespaceはコードやコマンドを動かす作業場です。Dopaはこの2つをiPadから扱います。

料金は3つに分けて確認する

  1. DopaのFree／Pro

    FreeでもAI・編集・Gitの機能は共通です。Proは端末内の会話・リポジトリの保存件数制限を解除する買い切り。FreeとProの比較を確認してください。

  2. GitHub Codespaces

    計算時間と保存容量はGitHub側の利用枠・契約に従います。作業場を起動する前に、GitHubの利用量と予算を確認してください。確認場所はGitHub公式の利用額確認ガイドに説明されています。停止しても保存容量の消費は続きます。

  3. Claude Code／Codex

    AIの料金・上限は、それぞれの提供者との契約や認証方法によります。DopaやProの購入にAIの利用枠は含まれません。

アプリを閉じた時点で課金対象の作業場が必ず停止するわけではありません。終了時の確認方法は作業の終え方へ。

初めてなら、ガイド付きで作品を作る

  1. 作品を選ぶ

    Welcomeから最初の作品づくりへ進みます。「自分のWebページ」「ブロック崩し」「光のアート」の3つから選んでください。

  2. GitHubとAIを選ぶ

    GitHubを認証し、Claude CodeかCodexを選びます。保存先は新しいリポジトリを作成します。名前と公開範囲を確認してください。

  3. 作業場を準備する

    費用の説明と設定内容を確認して、Codespaceを準備・起動します。接続が完了すると会話画面へ進みます。起動時間は環境や外部サービスの状態によって変わります。

  4. AIを認証して依頼する

    案内に従ってAIを認証します。送信する依頼と「作成条件を見る」の内容を確認してSEND。AIが作品の内容や設定を質問したら答えます。

  5. Previewで操作し、改造する

    生成されたWebページを読み込み、表示だけでなく操作も試します。ブロック崩しなら、実際にパドルを動かしてみましょう。変えたいところは同じ会話で依頼します。

ブロック崩しを遊んだあとの依頼例

ボールが速くて追いつけないので、速さを少し下げて。ブロックの数と色はそのままにして。

AIの出力は毎回同じではありません。表示できない場合はPreviewのエラー詳細を確認し、案内された修復依頼の内容を読んでから送信します。初回作品のPreviewはHTML・CSS・JavaScript向けで、任意の開発サーバーを表示する機能ではありません。

既存のリポジトリで始める

Welcomeで「GitHubで続ける」からクイック設定へ進みます。対象のリポジトリを選び、Codespaceを起動・接続。AIを認証すると、自分のプロジェクトへの依頼を送れます。

最初は構成や起動手順を確認し、次に変更をひとつ頼むと、差分を追いやすくなります。

READMEとディレクトリ構成を確認して、
このプロジェクトの起動手順とテスト方法を教えて。
まだファイルは変更しないで。

変更後は差分を確認し、必要なものをステージしてコミット・pushします。別のクライアントで始めたAIセッションをDopaへ取り込む機能はありません。

作業を終えるときに確認すること

  • 残したい変更を確認し、必要ならコミット・pushする。
  • Dopaの作業場の停止操作と表示を確認する。GitHubのCodespaces一覧からも状態を確認できます。自動停止の設定にも目を通す。
  • GitHub側でCodespacesの利用量・予算・保存容量を確認する。

停止と削除は別です。停止してもファイルの保存容量は使います。操作方法はGitHub公式の停止・再開ガイドでも確認できます。また、Dopaの会話履歴を消しても、GitHubのリポジトリやCodespaceは削除されません。

接続や認証で止まったら

作業場、AI認証、Preview、履歴ごとに、確認する項目をまとめています。
