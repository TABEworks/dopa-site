よくある質問

Codespaceが起動・接続できないときは？

Codespaceが停止中・起動中なら、Dopaに表示される準備状況を確認して、必要に応じて起動・再接続してください。起動には時間がかかることがあります。

接続拒否が出る場合は、接続詳細の理由と案内を確認。GitHub側で対象リポジトリへのアクセス、Codespacesの利用枠・予算もチェックしてください。エラーが続く場合は、秘密を隠した画面と再現手順をサポートへ。

Claude Code／Codexから応答がないときは？

Claude Code／Codexのログイン状態、承認や質問への返答待ち、提供者側の利用上限を確認してください。認証はDopaの案内に従って進めます。

会話履歴を開けても、CLI側のセッションが残っていなければ同じ文脈で続けられるとは限りません。再開に関する表示を確認してください。AIの応答品質や外部サービスの障害はDopaだけでは解消できません。

Dopa以外にどんな料金がかかりますか？

GitHub Codespacesの計算時間・保存容量と、Claude Code／Codexの利用料金は、各提供者との契約に従います。Dopaや買い切りのProに、その利用枠は含まれません。

アプリを閉じてもCodespaceがその瞬間に止まるとは限りません。作業を終えたら停止状態と自動停止の設定を確認してください。停止しても保存容量の消費は続きます。GitHubの利用量・予算もご確認ください。

Previewに作品が表示されないときは？

初回作品のPreviewは、Codespace上のHTML・CSS・JavaScriptを表示・実行します。作業場を再接続して再読み込みし、エラーがあれば詳細を確認してください。修復依頼の案内が出たら、会話の入力内容を確認してSENDします。

エディタのMarkdown・HTML・SVG・JSON表示は静的です。任意の開発サーバーを表示する機能ではありません。別のクライアントで始めたAIセッションの取り込みにも対応していません。

会話履歴の保存数と削除の条件は？

Freeで保存する履歴は1リポジトリ、会話はClaude Code・Codexそれぞれ1件。新しい会話や別リポジトリへの切り替えで旧履歴を置き換える場合は、削除前に確認します。残したいときはキャンセルしてください。

Dopa Proは、この端末に保存する履歴の件数制限をなくす買い切りです。AI機能はFreeでも全部使えます。空き容量は必要で、端末間同期・アプリ削除後の復元・購入前に削除した履歴の復活は含まれません。履歴の削除で、作品やGitHubのリポジトリ、Codespace、CLIセッションは削除されません。

Proの購入を復元するには？ アイコンが変わらないときは？

Settings → Dopa Proを開き、「Restore purchases（購入を復元）」を試してください。購入時と同じApple Accountを使います。承認待ちや権利確認のエラーが表示されている場合は、案内に従ってください。

Proの権利とアイコン変更は別です。Proが有効ならSettingsの「Use Pro icon」から再度変更を試せます。標準アイコンに戻してもProの権利は残ります。購入が確認できないまま再購入せず、解消しなければサポートへご連絡ください。

Dopa君のおしゃべり・ニュース・天気を減らすには？

Dopaの表示頻度設定で、おしゃべりを控えめにできます。ニュース・天気はSettingsで取得を無効にできます。接続失敗や認証など、作業に必要な案内は表示されます。サングラスは防音ではありません。

Frequently asked questions

My Codespace will not start or connect.

Check the Codespace preparation status in Dopa. Start or reconnect as needed; startup can take time. For rejected connections, check the reason and recovery instructions in connection details. Also check repository permissions, Codespaces limits and your GitHub budget. Still stuck? Send a redacted screenshot and reproduction steps.

Claude Code or Codex is not responding.

Check Claude Code/Codex authentication, pending approvals or questions, and provider usage limits. Follow Dopa's sign-in guidance. Reading saved history doesn't guarantee that the CLI session is still available to continue with the same context; check the resume message. Dopa cannot resolve every provider outage or AI response issue.

What costs are separate from Dopa?

You use your own GitHub and AI-provider accounts. Codespaces compute, storage and AI charges follow those agreements; Dopa and Pro don't include usage credits. Closing the app doesn't necessarily stop the Codespace immediately. Check its stopped state and idle timeout when finished. Stopped workspaces still consume storage. Check GitHub usage and budget settings.

My project is not showing in Preview.

First-project Preview runs HTML/CSS/JavaScript from your Codespace. Reconnect, reload, and check error details. If a repair prompt is offered, review it in Conversation before tapping SEND. Editor previews for Markdown/HTML/SVG/JSON are static. Arbitrary development-server previews and importing agent sessions from other clients aren't supported.

How is conversation history saved or deleted?

Free saves one repository's history and one conversation per agent. Dopa asks before replacing old history for a new conversation or repository; cancel to keep it. Pro is a one-time purchase that removes local history count limits. All agent features are available on Free.

Storage limits still apply. No device sync, recovery after deleting the app, or recovery of history deleted before purchase. Deleting Dopa history doesn't delete your project files, GitHub repository, Codespace or CLI session.

How do I restore Pro or change the app icon?

Open Settings → Dopa Pro → Restore purchases, using the Apple Account used for purchase. Check messages about pending approval or entitlement verification. Pro access and icon changes are separate: with Pro enabled, retry Use Pro icon in Settings. Choosing the standard icon doesn't remove Pro. Don't purchase again just to troubleshoot; contact us if restoration doesn't help.

How do I reduce chatter, news and weather?

Turn down Dopa's chatter frequency. Optional news and weather retrieval can be disabled in Settings. Essential authentication and error guidance still appears. Sunglasses aren't noise cancellation.
