01 / FROM IDEA TO COMMIT

「作って」で始めて、
自分で確かめる。

AIに投げっぱなしで終わらない。会話の続きも、変更の確認も、同じ作業場で。

01 — TALK

ざっくり頼む。途中で変える。

Claude CodeかCodexを選んで、作りたいものを会話で依頼。進行を見て、必要な操作を承認。「やっぱこうして」も送れるし、違うと思ったら中断できます。

02 — TRY

最初の作品は、その場で触る。

最初の作品づくりでは、生成されたWebページをPreviewで表示。実際に触って動きを確かめ、次の改造を同じ会話で頼めます。

03 — REVIEW & COMMIT

変わったところを、ちゃんと読む。

ファイルや差分のまとまりごとに変更を確認。必要ならコードを編集して、ステージ、コミット、pull、pushまで。勢いの証拠をGitに残そう。

05 / BEFORE YOU DOPA

作業場はクラウド。
手元は、iPad。

iPadDopaで依頼・確認↔GitHub CodespacesコードとAIが動く作業場

AIはあなたのCodespaceで動きます。iPadOS 17以降のiPad、ネット接続、GitHub Codespaces、Claude CodeまたはCodexの認証を用意してください。

DOPA FREE

まずは、ひとつのプロジェクト。

この端末で新規作成した1リポジトリ、AIごとに1会話を管理。会話を入れ替えるときは、ローカル履歴の削除前に確認します。

DOPA PRO / ONE-TIME PURCHASE

作るものが増えたら。

買い切りでリポジトリと会話の保存件数制限を解除。既存の作業環境の履歴も閲覧でき、金サングラスのProアイコンも使えます。

AIの機能はFreeもProも共通です。 GitHubの計算時間・保存容量とAIサービスの料金は別途かかる場合があり、Dopa／Proには含まれません。

履歴は端末に保存されます。空き容量が必要です。端末間同期や、削除した履歴の復元はできません。Freeでは作業環境の既存履歴を削除せず非表示にします。

HELLO, VIBE CODERS.

Unhinged ideas. Actual code.

Build with Claude Code or Codex on your iPad. Start with a personal website, Breakout, or light art—or jump into an existing GitHub repository. Talk to your agent, follow its progress, approve actions, and interrupt when you need to.

Try your first web project in Preview, then remix it. Read file and hunk diffs, edit code, use a remote terminal, and stage, commit, pull or push. Dopa, your small companion in sunglasses, brings encouragement and optional news and weather.

Requires iPadOS 17+, internet, GitHub Codespaces and agent authentication. Agents run in your Codespace. GitHub compute/storage and AI fees are separate. Free manages one repository and one new chat per agent on this device; Pro is a one-time purchase that removes saved-history count limits. History is local, with no device sync or deleted-history recovery. Agent features are shared by Free and Pro.

First-project Preview runs HTML/CSS/JS; file previews are static. Arbitrary dev-server preview and other-client session import are not supported.
