  1. 会話で依頼する

    Claude CodeかCodexを選び、作りたいものや変更を伝えます。途中の質問に答え、必要な操作を承認。方針が違えば中断できます。

  2. 変更を確かめる

    ファイルと差分を読み、必要ならエディタで修正。Markdown・HTML・SVG・JSONの静的表示と、リモートTerminalも使えます。

  3. Gitに残す

    残したい変更をステージして、コミット。リモートへのpush、更新を取り込むpullまでアプリ内で操作できます。

Dopaの料金と、外部サービスの料金。

AIへの依頼、コード編集、Git操作はFreeとProで共通です。Proは、この端末に保存する履歴を増やしたい人向けの買い切りです。

FreeとProの違い
Dopa内で管理するものFreePro（買い切り）
リポジトリ1つ保存件数の制限なし
新規会話AIごとに1件保存件数の制限なし
会話・リポジトリの切り替え置き換える履歴の削除前に確認履歴を保持
AI・編集・Git機能共通共通
ホーム画面アイコン標準金サングラスも選択可能

保存先は端末内です。空き容量が必要で、端末間同期や削除済み履歴の復元は含みません。Freeでは作業環境の既存履歴を削除せず非表示にします。

GitHub Codespacesの計算時間・保存容量と、AIサービスの利用料金は別です。 Dopa／Proの料金に含まれません。アプリを閉じてもCodespaceが即座に停止するとは限らず、停止後も保存容量は使います。

使い始める前の疑問。

プログラミングが初めてでも使えますか？

作品選びから進めるガイドを用意しています。ただし、GitHubとAIサービスの認証や利用料金の確認は必要です。AIの出力をそのまま信用せず、Previewや差分で結果を確認してください。始め方ガイドで流れを確認できます。

ChatGPTのチャットをiPadで開くのと何が違いますか？

Dopaでは、Codespace内のClaude Code／Codexがリポジトリのファイルやコマンドを扱います。iPadから、その進行・承認・コード差分・Git操作を確認できます。Dopaの会話機能は、このCLIとの接続です。

iPadだけで使えますか？ オフラインでも動きますか？

Dopaの初期設定と操作はiPadから進めます。コードやAIが動く場所はGitHub Codespacesなので、実行にはネット接続が必要です。iPad内で完結するオフライン開発環境ではありません。

App Storeで入手できますか？

現在、公開準備中です。このページのApp Storeリンクは仮のリンクで、ダウンロードにはまだ使えません。公開後に正式なリンクへ切り替えます。

Claude Code and Codex, from your iPad.

Dopa connects your iPad to your GitHub Codespace. Ask an agent to work on your repository, review its progress and approvals, edit files, inspect diffs, and stage, commit, pull or push.

Start with a guided website, Breakout game or light-art project, or select an existing repository. First-project Preview runs HTML/CSS/JS; file previews are static. Arbitrary dev-server previews and other-client session import are not supported.

Requires iPadOS 17+, internet, GitHub Codespaces and agent authentication. GitHub compute/storage and AI fees are separate. Free manages one repository and one new chat per agent; the one-time Pro purchase removes local history count limits. No device sync or deleted-history recovery. All agent features are shared.
